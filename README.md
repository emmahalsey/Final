# K-mer Analyzer

This program analyzes DNA sequences and counts k-mers and their following characters.

## How to run 
python kmer_analyzer.py input.txt k output.txt

## Running tests 
pytest

## Example
Input: 
ATCG

Output: 
AT C:1
TC G:1
